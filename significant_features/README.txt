Significant pre/post EEG features

The three CSV files list all significant hctsa features for each principal component:
PC1: 2,496 of 7,093 features tested
PC2: 3,021 of 7,116 features tested
PC3: 2,855 of 7,119 features tested

Two-sided paired Wilcoxon signed-rank tests compared normalised baseline and post-treatment values for 42 participants. Benjamini-Hochberg FDR correction was applied across all tested features within each PC. These lists include features with FDR-adjusted p < 0.05.

Columns:
FeatureID: hctsa feature identifier (study version 1.09)
FeatureName: hctsa feature name
Keywords: feature categories
P: unadjusted p-value
PFDR: FDR-adjusted p-value

Rows are ordered by feature ID, not classification accuracy. All of the manuscript's original top 40 features per PC are included. These are paired-test results, not the feature selections used for response prediction.
